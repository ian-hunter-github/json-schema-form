OneOf Accordion Fix Test

Test Description

This test verifies that checkShouldUseAccordion() is now called for oneOf fields themselves, not just for the branches.

Before the fix: oneOf fields would not be checked for accordion usage

After the fix: oneOf fields are checked and will use accordion if any branch has 3+ properties

✅ Build Status

Both the jsf-react package and demo application build successfully without errors.

This confirms that the TypeScript changes are syntactically correct.
