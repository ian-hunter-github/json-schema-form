OneOf Header Fix Test

Test Description

This test verifies that the oneOf header duplication issue has been fixed.

Before the fix: oneOf objects would show both the parent header (e.g., "Profile") and the branch header (e.g., "Person").

After the fix: oneOf objects should only show the parent header, not the branch header.

✅ Build Status

Both the jsf-react package and demo application build successfully without errors.

This indicates that the TypeScript changes are syntactically correct.

Visual Improvements

Additional styling has been added for better visual hierarchy:

  • Vertical spacing: 16px margin between oneOf selector and content
  • Indentation: 20px left margin with subtle border for visual hierarchy
  • Selector spacing: 8px bottom margin for the dropdown selector
  • Overall spacing: Increased bottom margin for oneOf containers

Next Steps

1. Open the demo at http://localhost:5173/

2. Look for the "Profile" section with the oneOf selector

3. Verify that when you select "Person" or "Company", the content appears with proper spacing and indentation

4. Check that no duplicate headers appear

Implementation Details

The fix involved:

  • Adding an isOneOfBranch parameter to the renderField function
  • Passing isOneOfBranch: true when rendering oneOf branches
  • Modifying object rendering to skip headers when isOneOfBranch is true
  • Rendering just the content without fieldset/legend or accordion headers for oneOf branches
  • Adding CSS styles for proper visual hierarchy and spacing
